# Changelog

GLOA Identity (the shared GLOA staff sign-in: Cognito user pool, app groups, login.galaxref.com).
Versions are MAJOR.MINOR.FIX: FIX = bug fix, wording or styling; MINOR = new feature or noticeable
change; MAJOR = redesign or a change people must re-learn. The number is in `VERSION`, and each release
is tagged `vX.Y.Z`.

## 1.0.0 — 2026-11-08
- Versioning starts here. The pool as of this release: login.galaxref.com; the post-sign-in hook
  that records each person's last sign-in; groups for every app (observation, incidents, video
  review, officials requests, rules test, coaches and officials registration, playoffs,
  communications) plus gloa-user-admins. History before this is in git.
